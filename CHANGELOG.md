# Changelog

## 0.1.0 — 2026-10-25

Initial Auralis implementation: React/TypeScript application shell and glass visual system, global media queue, demo/YouTube provider boundary, personal library and playlist flows, ASP.NET Core account and persistence API, PostgreSQL configuration, localization, Windows helpers, test scaffolding and provider research.

This version is not declared production-ready. Refer to `docs/VERIFICATION.md` for tested behavior, missing capabilities and external dependencies. Commits use actual creation timestamps and represent checkpoints of the accumulated implementation.
